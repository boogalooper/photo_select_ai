# Photo Select AI

Photo Select AI автоматически выбирает лучшие кадры большой фотосъёмки и отмечает их цветовыми метками, которые видны в Adobe Bridge и Lightroom.

Программа работает локально на компьютере. Фотографии никуда не отправляются, не удаляются и не перемещаются.

Есть два режима:

- **ПОРТРЕТЫ** — выбор лучших индивидуальных портретов;
- **ГРУППЫ** — выбор лучшего группового кадра и, при необходимости, дополнительных дублей.

Для большинства съёмок достаточно настроек по умолчанию.

---

## Установка

1. Распакуйте архив Photo Select AI в отдельную папку.
2. Запустите `install.bat`.
3. Выберите **1 — Normal secure mode**.
4. Дождитесь сообщения об успешной установке.
5. Запускайте программу через `run.bat`.

Для установки нужен интернет. Системный Python устанавливать не требуется: программа использует собственное локальное окружение.

Версии Python-пакетов зафиксированы полностью, включая транзитивные зависимости. Установщик не подбирает более новые версии автоматически, поэтому повторная установка использует тот же проверенный набор CPU/GPU-компонентов.

Если антивирус с проверкой HTTPS мешает загрузке пакетов, повторите установку и выберите **2 — Kaspersky compatibility mode**.

После успешной установки интернет для обычной обработки фотографий не требуется. Если обязательные файлы InsightFace будут удалены или повреждены, `run.bat` сообщит о необходимости восстановления. Если недоступна дополнительная модель оценки привлекательности лица, программа продолжит работу с резервным рейтингом качества.

---

## Быстрый старт

1. Запустите `run.bat`.
2. Выберите папку со съёмкой.
3. Выберите режим **ПОРТРЕТЫ** или **ГРУППЫ**.
4. Оставьте рекомендуемые настройки, если нет конкретной причины их менять.
5. Нажмите **НАЧАТЬ АНАЛИЗ**.
6. После завершения проверьте RED и YELLOW в Bridge или Lightroom.

Папка может содержать вложенные каталоги. Поддерживаются JPEG, TIFF, PSD, DNG и распространённые RAW-форматы камер.

# Цветовые метки

## RED

**RED — основной выбранный кадр.**

В режиме **ПОРТРЕТЫ**:

- в обычном режиме — один RED на каждую найденную портретную серию;
- в режиме разных поз — один лучший RED на ребёнка.

В режиме **ГРУППЫ**:

- один RED на каждую отдельную групповую серию.

## YELLOW

**YELLOW — дополнительный полезный кадр.**

В режиме **ПОРТРЕТЫ** YELLOW используется для лучших фотографий с заметно отличающимися позами, если включён соответствующий режим.

В режиме **ГРУППЫ** YELLOW может быть двух типов:

- кадр для исправления конкретной проблемы на RED, например для замены головы ребёнка с закрытыми глазами;
- хороший резервный дубль всей группы.

Поэтому YELLOW не обязательно является просто «вторым местом» общего рейтинга.

# Режим ПОРТРЕТЫ

## Обычный режим

Используйте его, когда каждый ребёнок снимается одной последовательной серией.

Рекомендуется:

```text
Портреты — режим выбора:            Обычный
Портреты — метод разделения серий:  dbscan
Профиль параметров серий:           Сбалансированный
```

Программа сначала разделяет съёмку на серии разных людей, затем выбирает лучший кадр каждой серии.

### Как выбирается лучший портрет

Порядок принципиальный:

1. проверяется пригодность кадра;
2. явно плохие варианты уступают пригодным;
3. среди лучших пригодных вариантов главным критерием становится Facial Beauty Prediction;
4. если эта модель не может надёжно сравнить серию, используется резервный рейтинг качества.

В портретном режиме считаются браком:

- явно закрытые глаза;
- явная нерезкость лица или глаз;
- плохое техническое качество.

**Поворот головы в портретном режиме разрешён** и сам по себе не ухудшает пригодность кадра.

Пограничные значения глаз и резкости не отбрасываются немедленно. Они считаются неопределёнными: такой кадр уступает достоверно хорошему, но остаётся доступным, если вся серия сложная.

## Один ребёнок в нескольких разных позах

Если одного ребёнка снимают несколькими отдельными сериями в заметно разных позах, выберите:

**«Один ребёнок / разные позы — лучший RED + позы YELLOW»**.

Программа постарается связать соседние серии одного человека, выбрать один лучший RED и добавить YELLOW для действительно отличающихся поз.

Небольшое изменение мимики, обычное перекадрирование или небольшой поворот головы сами по себе не должны создавать новую позу.

Лучше всего различаются позы, которые заметно отличаются по положению лица в кадре, масштабу и направлению головы. Изменение только рук или корпуса при почти одинаковом лице может быть распознано хуже.

---

## Если портретная серия определяется неправильно

### Пропущен ребёнок

Сначала включите:

**«Проверять пропущенные границы вторым методом»**.

Если этого недостаточно, попробуйте другой метод разделения серий: `dbscan` или `sequential`.

### Один ребёнок получил несколько RED

Попробуйте профиль серий **«Меньше повторов»**.

### Два разных ребёнка объединены в одну серию

Включите проверку пропущенных границ. Если проблема повторяется, попробуйте другой метод разделения.

---

# Режим ГРУППЫ

Рекомендуемые начальные настройки:

```text
Искать YELLOW / резервные дубли:  включено
YELLOW минимум / максимум:        1 / 3
Проверка взгляда в камеру:         включена
```

Количество физических групп заранее задавать не нужно. Программа анализирует последовательность кадров и старается отделить одну группу людей от следующей.

## Как выбирается RED группы

Для каждого кадра сначала проверяется пригодность. До оценки привлекательности учитываются:

- присутствие всех устойчиво распознанных участников группы;
- открытые глаза;
- допустимый поворот головы;
- резкость лица и глаз;
- техническое качество кадра и лиц.

Лицо, которое встретилось только на редких кадрах серии, не включается в обязательный состав группы. Это не позволяет случайному постороннему человеку повлиять на выбор RED.

Только после этого сравнивается привлекательность лиц.

Оценки разных людей напрямую между собой не сравниваются. Для каждого человека программа смотрит, на каких дублях **он сам** получился лучше, а затем ищет кадр, где удачно получилось максимальное число участников и нет слабого результата у остальных.

Если идеального кадра нет, выбирается наименее проблемный уровень пригодности. Оценка привлекательности не может компенсировать более тяжёлый технический брак.

Пограничные значения глаз и резкости считаются неопределёнными, а не автоматически плохими. Чистый кадр всегда имеет преимущество, но хороший пограничный дубль не теряется без необходимости.

## Поворот головы

В режиме **ГРУППЫ** заметный поворот головы считается проблемой пригодности. Это отличается от портретного режима, где поворот головы разрешён.

## Проверка взгляда в камеру

Если опция включена, сильнейшие групповые дубли дополнительно анализируются в большем разрешении. Проверка начинается с заданного короткого списка и автоматически расширяется следующими порциями, если хороший по взгляду кадр ещё не найден.

Сначала всегда сравнивается техническая пригодность. Внутри одинакового уровня пригодности преимущество получает кадр без уверенно отведённых взглядов и с достаточным количеством надёжно оценённых лиц. После выполнения этого минимального условия главным критерием снова становится Facial Beauty Prediction.

Слишком маленькие или ненадёжно измеренные глаза считаются неопределёнными и не получают искусственного штрафа.

Если контроль взгляда отключён, этот этап полностью пропускается: выбор выполняется по обычной схеме пригодность → Facial Beauty Prediction → резервный рейтинг качества.

## Как выбираются YELLOW

Сначала программа ищет кадры, которые помогают исправить конкретные проблемы RED. Например, если на RED у одного ребёнка закрыты глаза, YELLOW может содержать хороший вариант его лица для ручной замены.

Если таких кадров меньше заданного минимума, добавляются резервные дубли. Резервный YELLOW выбирается только среди кадров того же уровня пригодности, что и RED. Если для безопасных кандидатов уже выполнена финальная проверка взгляда, она применяется и к резерву; иначе используется обычный рейтинг качества лица.

Если безопасного резервного дубля нет, программа не обязана создавать плохой YELLOW только ради достижения заданного минимума.

На главном экране выберите схему меток.

## Adobe Bridge

- RED → `Select`
- YELLOW → `Second`

## Lightroom

Стандартные значения:

- RED → `Red`

# Повторный анализ той же съёмки

Photo Select AI сначала полностью анализирует съёмку и формирует новый план RED/YELLOW. Только после успешного анализа начинается запись метаданных.

Если анализ отменён или завершился ошибкой **до финальной записи**, существующие RED/YELLOW не изменяются.

Если программа не смогла выбрать ни одного RED или не смогла сформировать RED для уже подтверждённой серии, старые метки также сохраняются. Пустой или заведомо неполный результат не используется как команда очистки съёмки.

При успешном плане финальная запись выполняется так:

1. очищаются старые значения RED/YELLOW на найденных ресурсах;
2. записывается новый план RED/YELLOW.

При смене встроенной схемы Bridge/Lightroom программа также распознаёт и очищает старые метки другой встроенной схемы. Произвольные посторонние значения `xmp:Label` не удаляются.

Если при финальной записи хотя бы один файл не удалось корректно изменить, запуск завершается ошибкой. В этом редком случае часть метаданных уже может быть изменена; проверьте журнал и повторите анализ после устранения причины.

Другие XMP-данные — рейтинг, ключевые слова, настройки проявки, кадрирование, маски и прочие поля — не должны удаляться.

# Работа с RAW, JPEG, TIFF, DNG и PSD

Для проприетарных RAW-файлов, например CR2/CR3, NEF, ARW и RAF, программа использует внешний sidecar `.xmp` и не изменяет байты RAW.

DNG и TIFF могут использовать встроенный XMP. JPEG использует стандартный встроенный XMP. Для PSD программа изменяет XMP внутри Photoshop Image Resources, если это можно сделать безопасно.

При очистке RAW-меток существующий `.xmp` **не удаляется**: изменяется только нужная цветовая метка.

Точная пара RAW+JPEG с одинаковым именем без расширения рассматривается как одна экспозиция. Обычно анализируется RAW, а JPEG может использоваться как резервный preview. Итоговая логическая метка синхронизируется на оба физических файла с учётом правил соответствующего формата.

# Производительность

Если скорость устраивает, оставьте настройки по умолчанию.

## Потоки CPU

Они используются для чтения метаданных и подготовки preview. Слишком большое число потоков не всегда ускоряет работу.

## Параллельный InsightFace

Дополнительные GPU-сеансы могут ускорить некоторые съёмки, но увеличивают расход видеопамяти. Начинайте с одной сессии и увеличивайте число только после проверки результата и расхода VRAM.

## Безопасное управление VRAM

Эту опцию рекомендуется оставлять включённой.

Если видеопамяти не хватает:

1. уменьшите число параллельных GPU-сеансов;
2. оставьте безопасное управление VRAM включённым;
3. при необходимости временно отключите финальную проверку взгляда в Group.

# Прогресс, отмена и журнал

Во время работы отображаются текущий этап и общий прогресс.

Кнопка **Отмена** останавливает анализ при ближайшей безопасной точке. Если финальная запись XMP уже началась, небольшой этап записи завершается целиком, чтобы отмена не оборвала его посередине.

Подробный журнал находится здесь:

```text
logs/photo_select_ai.log
```

Сохраните его, если:

- пропущен ребёнок;
- серии неожиданно объединились или разделились;
- выбран неожиданный RED;
- YELLOW выглядит неподходящим;
- программа сообщила об ошибке установки, анализа или записи метаданных.

При разборе проблемы полезно также записать номера соответствующих файлов.

# Расширенные настройки

Используйте их только для решения конкретной проблемы.

Основные случаи:

- нужно изменить чувствительность разделения портретных серий;
- нужно настроить режим разных поз;
- слишком маленькие лица в группе не распознаются;
- требуется изменить чувствительность детектора или проверки взгляда;
- нужно уменьшить расход VRAM или изменить число рабочих потоков.

Если назначение параметра непонятно, оставьте рекомендуемое значение.

Кнопка **«Вернуть все рекомендуемые значения»** возвращает стандартные настройки.

### Одиночный портрет в DBSCAN

Если итоговая серия должна состоять всего из одного кадра, недостаточно поставить только **«Мин. кадров итоговой серии = 1»**. Для DBSCAN также установите **«Мин. уверенных кадров серии = 1»**. По умолчанию значение 2 специально защищает от одиночных ложных распознаваний.

# Перенос программы

Папку Photo Select AI можно переименовать или перенести на другой локальный диск.

После переноса запускайте обычный `run.bat`. Скрипт проверит локальное Python-окружение и при необходимости восстановит привязку к новому пути. Если окружение отсутствует или серьёзно повреждено, будет предложено снова запустить `install.bat`.

На другом компьютере может потребоваться повторная установка, особенно если отличается видеокарта или набор драйверов.


Для обычной работы удобнее выбрать папку через интерфейс.

# Если программа не запускается

1. Запустите `run.bat` ещё раз и прочитайте сообщение в консоли.
2. Если предлагается восстановление окружения — дайте ему завершиться.
3. Если требуется полная переустановка — запустите `install.bat`.
4. Проверьте `logs/photo_select_ai.log`.
5. Для GPU-режима убедитесь, что драйвер NVIDIA установлен и работает.

Если дополнительная модель Facial Beauty Prediction недоступна, это не должно блокировать обработку: программа сообщает о fallback и продолжает выбор по резервному рейтингу.
