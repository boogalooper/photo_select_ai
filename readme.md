# Photo Select AI

Программа выбирает лучшие фотографии из серий и ставит цветовые метки для Adobe Bridge или Lightroom. Подходит для постановочных портретных и групповых съёмок детей и взрослых.

Работает локально на Windows. Фотографии никуда не отправляются, не удаляются и не перемещаются. Метаданные изменяются для записи меток.

## Установка и запуск

1. Распакуйте архив в отдельную папку.
2. Запустите `install.bat`, выберите **1 — Normal secure mode** и дождитесь успешного завершения.
3. Запустите `run.bat`.
4. Выберите папку со съёмкой, режим **ПОРТРЕТЫ** или **ГРУППЫ** и схему меток Adobe.
5. Нажмите **НАЧАТЬ АНАЛИЗ**. После завершения проверьте результат в Bridge или Lightroom.

Интернет нужен для установки пакетов и моделей. Python отдельно устанавливать не требуется. Версии зависимостей зафиксированы; вручную обновлять их не нужно.

Режим **2 — Kaspersky compatibility mode** используйте только при ошибках проверки сертификатов при загрузке пакетов: он отключает эту проверку для серверов PyPI.

После установки анализ работает без интернета. Если обязательные модели отсутствуют или повреждены, повторите установку. Если недоступна дополнительная модель оценки привлекательности, программа сообщает об этом и использует обычную оценку качества.

Вложенные папки тоже обрабатываются. Поддерживаются JPEG, TIFF, PSD, DNG и распространённые RAW, включая CR2, CR3, NEF и ARW.

## Что означают метки

| Режим | RED — красная | YELLOW — жёлтая |
| --- | --- | --- |
| Портреты, обычный выбор | Лучший кадр каждой найденной серии | Не используется |
| Портреты, разные позы | Один лучший кадр среди связанных серий одного человека | Лучшие кадры других заметно отличающихся поз |
| Группы | Один основной кадр каждой групповой серии | Кандидаты для ручной замены лиц и резервные дубли |

Программа только отмечает фотографии. Заменять лица и собирать итоговый групповой снимок нужно вручную.

## Портреты

Сначала программа разделяет съёмку на серии одного человека. Затем сравнивает кадры: открытые глаза, резкость лица и техническое качество имеют приоритет перед привлекательностью.

Среди наиболее пригодных кадров используется **FBP (Facial Beauty Prediction)** — модель оценки привлекательности лица. Если надёжного сравнения нет, применяется обычная оценка качества. Результат модели может отличаться от вашего вкуса.

**Поворот головы в портретах разрешён.** Он сам по себе не считается браком. Неуверенные оценки глаз и резкости уступают уверенно хорошим, но не исключаются безусловно.

Для начала оставьте метод разделения **dbscan** и профиль **«Сбалансированный»**.

Если один человек снят в нескольких позах, включите **«Один ребёнок / разные позы — лучший RED + позы YELLOW»**. Программа постарается связать соседние серии одного человека. Позы различаются по положению лица, масштабу и углам головы; изменение только рук или корпуса может остаться незамеченным.

Если серии разделены неправильно:

- пропущена граница между людьми — включите **«Проверять пропущенные границы вторым методом»**;
- слишком много повторных RED — попробуйте профиль **«Меньше повторов»**;
- проблема сохраняется — попробуйте другой метод разделения: `dbscan` или `sequential`.

Для одиночных портретных серий в DBSCAN установите **«Мин. кадров итоговой серии»** и **«Мин. уверенных кадров серии»** равными `1`. По умолчанию защита от одиночных ложных распознаваний может исключать такие серии.

## Группы

Начальные настройки: **поиск YELLOW включён**, **минимум / максимум — 1 / 3**, **проверка взгляда включена**.

**«Мин. лиц в группе»** — число людей для распознавания группы, а не количество классов или групп в папке. По умолчанию — `4`. Участниками могут быть дети и взрослые.

Основной RED выбирается в таком порядке:

1. Присутствие устойчиво распознанных участников, открытые глаза, допустимый поворот головы, резкость и техническое качество.
2. Взгляд в камеру, если его проверка включена и получены надёжные оценки.
3. Привлекательность лиц: предпочтение кадру, где больше участников удачно получились относительно собственных дублей.

Если все дубли сложные, программа выбирает наименее проблемный из доступных. Но группа должна сначала быть распознана: слишком мало обнаруженных лиц, недостаточно повторных наблюдений или слишком короткая серия могут помешать выбору. Лица, встречающиеся лишь изредка, могут не включаться в постоянный состав группы.

### Голова и взгляд — разные проверки

В группах заметный **поворот головы** учитывается при оценке пригодности. Проверка **взгляда** дополнительно оценивает лучшие дубли в большем разрешении. Если в первой порции подходящего взгляда нет, список проверки расширяется.

Отключение флажка взгляда убирает дополнительный проход, но сохраняет проверку поворота головы, глаз и резкости. Слишком маленькие или плохо различимые глаза считаются неопределёнными.

### Сколько будет YELLOW

Сначала выбираются кадры, которые помогают исправить конкретные проблемы RED, например закрытые глаза одного из участников.

| Минимум / максимум | Результат на одну групповую серию |
| --- | --- |
| `0 / 3` | Автоматически: от 0 до 3 полезных кандидатов для исправления RED |
| `2 / 3` | От 2 до 3 YELLOW, если хватает разных снимков |
| `2 / 2` | Ровно 2 YELLOW, если хватает разных снимков |
| `0 / 0` | Только RED |

При минимуме выше нуля программа обязательно добирает резерв: сначала наиболее пригодные кадры, затем лучшие из оставшихся. Поэтому принудительный резерв может содержать недостатки.

Максимум — жёсткий предел, допустимый диапазон — `0–5`. Минимум не может превышать максимум. Все YELLOW идут **дополнительно к одному RED**.

Для RED + 2 YELLOW нужны хотя бы три разных ресурса. Файлы в одной папке с одинаковым именем без расширения считаются одним ресурсом. При нехватке кадров выбирается доступное количество, в журнал записывается предупреждение.

Если **«Искать YELLOW / резервные дубли»** отключено, YELLOW не создаются.

## Имена файлов и время съёмки

Программа использует числовой индекс в имени и при необходимости читает время съёмки из EXIF. Чтение EXIF выборочное: число EXIF-чтений может быть меньше числа фотографий. Это нормально и одинаково работает в обоих режимах.

Поддерживаются имена вида `1А IMG_1719.CR2` и суффиксы вроде `IMG_1719_edit.jpg`. При нестандартных именах проверяйте результат разделения серий. Префикс класса помогает различать последовательности, но не заменяет проверку состава группы.

Высокое ISO само по себе не является запретом на выбор. Шум может затруднить распознавание лиц и оценку резкости.

## Метки в Bridge и Lightroom

| Схема | RED | YELLOW |
| --- | --- | --- |
| Bridge | `Select` | `Second` |
| Lightroom | `Red` | `Yellow` |

Если вы переименовали цветовые метки в Adobe, выберите **Custom** и введите точные названия.

## Что меняется в файлах

Для обычных RAW, например CR2, CR3, NEF и ARW, метка записывается в соседний файл `.xmp`; сам RAW не изменяется. Существующий `.xmp` не удаляется.

JPEG, DNG, TIFF и PSD могут получать метку внутри исходного файла. Код меняет поле цветовой метки, сохраняя остальные метаданные, включая настройки проявки, рейтинг и маски.

Точная пара RAW + JPEG обычно анализируется один раз; метка синхронизируется на оба файла.

При повторной обработке сначала заканчивается анализ, затем очищаются старые RED/YELLOW и записывается новый выбор. Очистка затрагивает и соответствующие метки, поставленные вручную, включая встроенные названия другой схемы Bridge/Lightroom.

При отмене до записи метаданные не меняются. После начала записи отмена откладывается до её завершения. **Общего отката нет:** при ошибке диска или записи часть файлов уже может быть изменена. Для ценных исходников сохраняйте резервную копию.

## Скорость и настройки

Начните с рекомендуемых значений. Увеличение размера изображения для анализа помогает различать маленькие лица, но требует больше времени и памяти. Дополнительные GPU-сеансы увеличивают расход видеопамяти и не всегда ускоряют работу.

При нехватке видеопамяти уменьшите число параллельных GPU-сеансов и оставьте защиту VRAM включённой. Проверку взгляда можно отключить для ускорения группового анализа.

Подсказки появляются при наведении на настройки. Кнопка **«Вернуть все рекомендуемые значения»** восстанавливает стандартные параметры.

## Если что-то пошло не так

При пропуске человека или целой группы сначала проверьте сводку: сколько файлов найдено, сколько исключено из-за ошибок и сколько серий оказались слишком короткими. Не ослабляйте критерии качества, пока не убедитесь, что нужные файлы вообще попали в анализ.

Для разбора проблемы сохраните:

- `logs/photo_select_ai.log` — подробный журнал обработки;
- `config/ui_state.json` — сохранённые настройки интерфейса;
- имена пропущенных или неверно выбранных фотографий и пример кадра.

Если установка не завершилась, сохраните текст ошибки из окна установщика. Если программа не запускается, прочитайте сообщение `run.bat`; при запросе восстановления запустите `install.bat`.

## Обновление и перенос

Перед обновлением закройте программу. Замените файлы из нового архива, сохранив установленные папки `runtime` и `models`. Если изменились зависимости или требуется восстановление, запустите `install.bat`.

Папку программы можно переименовать или перенести. После этого запускайте `run.bat`: он проверит окружение и при необходимости восстановит его. На другом компьютере может понадобиться повторная установка.

Папку со съёмкой можно передать сразу при запуске:

```bat
run.bat "D:/Photos/Shoot"
```

Программа предназначена для личного некоммерческого использования.
